BACKUP E PROTEÇÃO DE DADOS

Segurança das informações

O GUI E NOIA VEÍCULOS utiliza uma solução de backup para auxiliar na proteção e recuperação dos dados do seu sistema de gerenciamento.

Integração com Google Drive

O aplicativo utiliza autorização Google OAuth para armazenar cópias de segurança na conta Google autorizada.

O acesso ao Google Drive é utilizado exclusivamente para as operações de backup autorizadas.
